# ตรวจรับสินค้าขาเข้า UAM

เว็บแอปตรวจรับชิ้นส่วนขาเข้าบนมือถือและไอแพด สำหรับ UAM Factory 1
ถ่ายรูปใบรายการสินค้า → ระบบอ่านรายการและแบ่งตามลัง → เปิดทีละลังแล้วกดนับ → ปิดล็อตพร้อมเหตุผลของรายการที่ยอดไม่ตรง
ข้อมูลเก็บใน Supabase และอัปเดตทุกเครื่องทันที

## ใช้งาน

1. เปิดลิงก์ GitHub Pages ของ repo นี้บนมือถือหรือไอแพด
2. ใส่ชื่อผู้ตรวจนับ และรหัสหน้างาน 6 หลัก (ขอจากหัวหน้างานตรวจรับ)
3. iPhone/iPad: กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" เพื่อเปิดเหมือนแอป

### ขั้นตอนหน้างาน
- **รับของใหม่** → ถ่ายรูปใบรายการ (หลายหน้าได้) → ตรวจบรรทัดสีเหลือง → บันทึก
- **นับตามลัง** → แตะลังที่เปิด → ถ้าของครบกด **ลังนี้ครบตามเอกสาร** ครั้งเดียว หรือกด `+จำนวน` ทีละรายการ
- **ค้นหาตามรหัส** → พิมพ์แค่เลขท้าย เช่น `566`
- **สแกนป้าย** → ถ่ายป้ายกล่อง ระบบอ่านรหัสและจำนวนให้กดยืนยัน
- **ย้อนกลับ** → ยกเลิกการกดครั้งล่าสุด (รวมทั้งการกด "ครบทั้งลัง")
- **ปิดล็อต** → ใส่เหตุผลให้ทุกรายการที่ขาด/เกิน/เสียหาย แล้วยืนยัน

เน็ตหลุดระหว่างนับได้ ระบบเก็บไว้ในเครื่องและส่งเองเมื่อกลับมาออนไลน์ (ดูป้ายมุมขวาบน)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML/CSS/JS ไฟล์เดียว, supabase-js จาก CDN) |
| `supabase/migrations/001_init.sql` | ตาราง, RLS, realtime, view `v_part_summary` |
| `supabase/functions/read-doc/index.ts` | Edge Function อ่านเอกสาร/ป้ายด้วย Gemini |
| `supabase/seed_k1g_example.sql` | ล็อตตัวอย่าง K1G 2538 WHEELS |

### ตารางใน Supabase (โปรเจกต์ UAM Incoming Inspection)
- `receipts` ล็อตรับของ
- `receipt_lines` บรรทัดในใบรายการ (รหัส, ลัง, จำนวน)
- `count_events` ทุกครั้งที่กดนับ (ใคร, เมื่อไร, ลังไหน) ย้อนกลับ = `voided`
- `part_notes` เหตุผลของรายการที่ยอดไม่ตรง
- `v_part_summary` สรุปต่อรหัส ใช้ต่อกับ Excel / Power BI ได้

### ความปลอดภัย
- อ่านข้อมูลได้ด้วย public key (เพื่อให้ realtime ทำงาน)
- เขียนข้อมูลได้เฉพาะเมื่อส่งรหัสหน้างานถูกต้อง (header `x-site-key` ตรวจใน RLS)
- รหัสหน้างานเก็บในตาราง `app_config` ซึ่ง API เข้าถึงไม่ได้ เปลี่ยนรหัส:
  `update public.app_config set value = 'รหัสใหม่' where key = 'site_key';`
- Gemini API key เก็บเป็น secret ของ Edge Function ไม่อยู่ในหน้าเว็บ

### ตั้งค่า AI อ่านเอกสาร
Supabase → Edge Functions → Secrets → เพิ่ม `GEMINI_API_KEY` (เปลี่ยนรุ่นได้ด้วย `GEMINI_MODEL`, ค่าเริ่มต้น `gemini-2.5-flash`)
